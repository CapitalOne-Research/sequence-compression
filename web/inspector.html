§ 01.

Sequence

The feature sequence is the unit of compression. Paste the values for a single feature column — channel IDs, interaction counts, embedding scores, or event timestamps. JSON array, comma-separated, or one per line. Strings stay as strings; bare numbers are coerced to numeric.

Pipeline

Compose a pipeline for this feature. Steps apply left-to-right; auto resolves to the smallest valid chain via depth-3 search. Common recommender pipelines: cat_rle_bp for channel IDs · del_bp for timestamps · nbp for sparse counts.
