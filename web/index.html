Compression Playground

An interactive instrument for compressing recommender feature payloads — drop a parquet or csv file containing user or item feature sequences and route each column through a pipeline of your choosing.

✦ encoder ✦ inspector → ✦ schemes → ✦ recsys example →
§ 01.

Intake

Drop a feature payload file. The playground profiles each column, infers the statistical shape of the sequence (categorical channel IDs, sparse interaction counts, dense embeddings, event timestamps, etc.), and recommends a compression pipeline suited to that shape.

  • .csv via pandas
  • .parquet via pyarrow
  • utf-8 compact json sizing

¹ Encoding is only retained when the encoded payload is strictly smaller than the original — a behaviour inherited from encode_feature_payload and surfaced here verbatim.

§ 03.

Pipeline Composition

Compose an encoding pipeline per feature column. Steps apply left‑to‑right; the decoder reverses them. Most recommender feature pipelines follow the rhythm of transform → reduce → pack — e.g. cat_rle_bp for sparse channel IDs or del_bp for monotone event timestamps.
